# Optimization Settings

This file will record the exact computational settings used for every final experiment.

## Required settings

- algorithm implementation/library,
- population size,
- number of generations,
- crossover operator and probability,
- mutation operator and probability,
- initialization method,
- repair/feasibility handling,
- random seeds,
- number of independent runs,
- termination rule,
- machine/runtime environment.

## Rule

No final table or figure should be reported without the run configuration and seed being recoverable.
