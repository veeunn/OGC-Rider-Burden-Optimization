# Data Description

## Source

Optimization Grand Challenge 2024 food-delivery problem instances.

## Supplied stages

- Stage 1
- Stage 2
- Stage 3

## Core fields

The supplied problem description shows that each instance contains rider attributes, order attributes, and a distance matrix.

Rider data include transport type, speed, capacity, cost parameters, service time, and rider availability.

Order data include pickup/delivery coordinates, ready time, order volume, and deadline.

The distance matrix has size 2K × 2K for K orders.

## Study filter

Only BIKE riders are retained in the research analysis.
